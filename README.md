# PINTAR MEMILIH – Media Edukasi Kepemiluan

## Menjalankan website
1. Ekstrak folder `PINTAR-MEMILIH`.
2. Buka folder tersebut melalui Visual Studio Code.
3. Jalankan `index.html` menggunakan ekstensi Live Server.
4. Navigasi utama tersedia pada bagian atas setiap halaman: Beranda, Tentang, Materi, Dashboard, dan Kuis.

## Pembaruan pada versi ini
- Navigasi diperjelas dengan latar merah KPU, teks putih, ikon, dan kontras yang lebih kuat.
- Tautan Dashboard ditambahkan ke seluruh halaman.
- Dashboard didesain ulang dengan ringkasan progres, kartu statistik, daftar status materi, dan ilustrasi pemilu.
- Ilustrasi kotak suara dan surat suara disimpan lokal di `assets/images`.
- Penamaan halaman dan JavaScript Dashboard diseragamkan menjadi `dashboard.html` dan `dashboard.js`.
- Tampilan dibuat responsif untuk desktop, tablet, dan ponsel.

## Catatan
Ilustrasi kotak suara merupakan ilustrasi edukasi, bukan logo resmi KPU. Jika diperlukan, logo resmi KPU dapat ditambahkan dari aset resmi yang dimiliki instansi.
